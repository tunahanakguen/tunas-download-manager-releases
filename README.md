# TUNAS Download Manager

<img src="TunasLogo.png" alt="TUNAS" width="160">

Download-Manager für Windows nach dem Vorbild des Internet Download Manager: segmentierte, wiederaufnehmbare
Downloads, Warteschlangen mit Zeitplan, Übernahme aus Chrome und Edge, Videos in wählbarer Qualität.

Dieses Repository enthält nur die fertigen Setups. TUNAS sucht hier selbst nach Updates.

## Herunterladen

Unter [Releases](../../releases/latest) die Datei `TUNAS-Download-Manager-Setup-<Version>.exe` laden und ausführen.

- Windows 10 (1809) oder 11, 64 Bit. Keine Administratorrechte nötig, .NET ist enthalten.
- Prüfsumme: `TUNAS-Download-Manager-Setup-<Version>.exe.sha256` (SHA-256).
- Die Browser-Erweiterung wird nach der Installation als „entpackte Erweiterung“ geladen;
  die Abschlussseite des Setups zeigt den Weg.
